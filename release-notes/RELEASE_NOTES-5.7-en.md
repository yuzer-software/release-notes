# November 2026 - Version 5.7

yuzSection Bug Fixes and Improvements

## Improvements

- The task dialog box now displays time spent as progress relative to planned time.
- You can now configure comment exports within the file export settings.
- A workshop manager can now reopen a closed task.
- Improved size management for products.
- Improved error display when importing basket templates (packages).
- Improved rendering of certain descriptions in product details.
- It is now possible to configure the server scheme ((S)FTP(S)) in the accounting export settings.
- It is now possible to disable an access/service.
- It is now possible to edit a proforma invoice or deposit invoice without an ID on the IDP.
- It is now possible to select the receiving action (prepare/reserve) during a transfer receipt.

## Bug Fixes

- Fixed the return of an intra-entity transfer.
- Fixed category selection in stock and sales analytics.
- Fixed the breadcrumb display showing the hierarchy of the currently displayed analytics table.
- Fixed the handling of merging two identified product records (vehicles) during a transfer receipt.
- For a multi-IDP basket, all files are now properly reserved when editing a purchase order.
- Fixed errors when modifying catalog enrichment rules.
- Fixed the currency displayed on certain screens for users outside the Eurozone.
- Fixed the locale used for displaying dates and added support for South Africa.
- It is now possible to edit optional contact fields on an entity, rather than only required fields.
- Fixed the handling of certain error statuses that were previously ignored on YUZER PAY terminals.
- It is once again possible to create legacy API keys.
- Fixed the display of the access list after editing one of the entries.
