# December 2026 - Version 5.8

yuzSection Bug Fixes and Improvements

## Improvements

- It is now possible to aggregate by product reference in analytics.
- It is now possible to group by label in network analytics.
- Performance improvements for variant support.
- An entity administrator can now configure an email account per user:
  - If the person issuing a document has a configured email account, it is used to send the document.
  - Otherwise, the entity's email account is used.
- Customer balance details can now be filtered and exported.

## Bug Fixes

- Fixed certain scenarios where receipt accounting statuses were not properly updated when validating a purchase invoice.
