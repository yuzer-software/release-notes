# Décembre 2026 - Version 5.8

yuzSection Corrections et améliorations

## Améliorations

- Il est désormais possible d'effectuer une aggrégation sur la référence produit dans l'analytique.
- Il est désormais possible de grouper par libellé dans l'analytique réseau
- Améliorations de performance sur le support des variants.
- L'administrateur d'une entité peut désormais configurer un compte email par utilisateur
  - Si la personne qui édite un document a un compte email configuré alors celui-ci est utilisé pour envoyer le document
  - Dans le cas contraire c'est le compte de l'entité qui est utilisé.
- Le détail d'une balance client peut désormais être filtré et exporté.

## Corrections

- Correction de certains scenarios ou les statut comptables de réceptions n'étaient pas bien mis à jour lors de la validation d'une facture d'achat.
